# Examples

Run `flutter run` in this folder and pick an example from the list.

| Example | Shows |
|---|---|
| [Daily view](lib/examples/daily_view.dart) | All-day events, drag and resize on a single day. |
| [Weekly view](lib/examples/weekly_view.dart) | Weekly time grid, drag, resize and taps on empty slots. |
| [Monthly view](lib/examples/monthly_view.dart) | Month grid with a recurring event. |
| [Agenda](lib/examples/agenda_view.dart) | Sequential scrolling, custom header and swipe actions. |
| [Recurring events](lib/examples/recurrences.dart) | Patterns, RRULE import and dragging a whole series. |
| [Custom event type](lib/examples/custom_event.dart) | Subclassing `Event` and typing the calendar on it. |

The view examples share the events defined in [sample_events.dart](lib/sample_events.dart).
